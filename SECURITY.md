# Security policy

This pre-release foundation has no supported production version.

Report vulnerabilities privately through GitHub's **Report a vulnerability** feature when enabled. Otherwise contact the maintainer privately through the contact details on the GitHub profile of `timfromhcs`. Include the affected revision, impact, reproduction conditions, and a minimal redacted example. Keep credentials, wallet material, and identifiable transaction data out of reports.

Maintainers triage reports privately, prioritize containment and regression tests, and coordinate disclosure with the reporter after a fix or mitigation is available.
