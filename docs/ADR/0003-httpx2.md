# ADR 0003 — HTTP client: httpx2

Status: accepted.

The application declares `httpx2>=2.16.0` as its HTTP client and `uv.lock` pins 2.16.0. The pinned MCP SDK line (`mcp` 2.3.0) also requires it.

## Provenance

- `httpx2` is the Pydantic-maintained continuation of HTTPX. [PyPI project](https://pypi.org/project/httpx2/) · [Source repository](https://github.com/pydantic/httpx2)
- PyPI metadata declares the license as BSD-3-Clause and links the project homepage and source to `github.com/pydantic/httpx2`.
- `uv.lock` records the sdist and wheel SHA-256 hashes from PyPI. `uv sync --locked` installs only those artifacts.

## Decision

Use `httpx2` for application HTTP calls instead of adding the original `httpx` alongside it. A single client avoids two copies of the same transport stack, matches the MCP SDK dependency, and keeps timeouts, redirects and response bounds in one implementation.

## Consequences

- The package name differs from the original `httpx`. Reviewers should confirm the exact name `httpx2` and its PyPI publisher on upgrades to rule out typosquatting.
- Upgrades follow the normal Dependabot review: read the changelog, keep the lockfile hashes and rerun the full test suite.
- The license inventory (`scripts/license_inventory.py`) must continue to report BSD-3-Clause for this package.
